# SQL Portfolio — системный аналитик

Учебный проект: аналитика финансовых операций небольшой компании.
Задача проекта — показать полный цикл работы аналитика с данными:
проектирование схемы, подготовка данных, аналитические запросы,
контроль качества данных и витрина для бизнес-пользователей.

## Структура репозитория

- `schema.sql` — схема БД: 2 справочника + таблица операций, внешние ключи, индексы
- `seed.sql` — тестовые данные за август–октябрь 2026 (183 операции, обезличенные)
- `view.sql` — витрина `v_transactions_wide` для бизнес-пользователей
- `queries/` — SQL-запросы под конкретные бизнес-задачи
- `results/` — результаты запросов в CSV (выгрузки из DBeaver)
- `diagrams/` — ER- и BPMN-диаграммы проекта (draw.io)

## Запросы и задачи

| Задача | SQL-файл | Результат | Что показывает |
|--------|----------|-----------|----------------|
| Динамика выручки месяц к месяцу | `growth_by_employee.sql` | `results/growth_by_employee.csv` | Оконная функция LAG, рост/падение в % |
| Скользящее среднее за 7 дней | `sliding_avg.sql` | `results/sliding_avg.csv` | Окно ROWS BETWEEN, сглаживание пиков |
| Поиск аномальных операций | `anomalies.sql` | `results/anomalies.csv` | Отклонение от среднего по группе |
| Поиск дублей операций | `duplicates.sql` | `results/duplicates.csv` | GROUP BY + HAVING |
| Маппинг кодов в бизнес-категории | `mapping.sql` | `results/mapping.csv` | JOIN со справочником (как в интеграциях) |
| Контроль качества данных | `data_quality.sql` | `results/data_quality_check_*.csv` | Пропуски, нарушение бизнес-правил, пороговые проверки |
| Отчёт из витрины | `simple_report.sql` | `results/simple_report.csv` | Понятный слой над схемой |


## Как воспроизвести

1. Открыть DBeaver → новое соединение SQLite → создать пустой файл БД.
2. Выполнить по порядку: `schema.sql` → `seed.sql` → `view.sql`.
3. Выполнять запросы из `queries/` по одному.
4. Для PostgreSQL использовать версию `growth_by_employee_postgres.sql`
   и `anomalies_postgres.sql` (полное правило «3 сигм» через STDDEV_POP).
